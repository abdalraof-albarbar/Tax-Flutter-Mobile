# سجل الإصدارات

## [0.4.0](releases/0.4.0.md)

- الترحيب والتعريف والدخول والتسجيل والاستعادة التجريبية، مع صورتين أصليتين.
- المساعدة والخصوصية والإشعارات وإغلاق التجربة دون حذف البيانات المحلية.
- نماذج متجاوبة وحالات فشل وإعادة محاولة، دون خادم حسابات أو حزم جديدة.

## [0.3.0](releases/0.3.0.md)

- بطاقة هوية جديدة للمفتش، واختيارات منزلقة، ومعاينة قراءة وتخطيط متجاوب.
- تحسين Hero وانتقال الصفحة واستجابة الصورة، مع تطبيق تقليل الحركة على الرجوع.
- نفس البيانات والخدمات، دون حزم إضافية؛ [التفاصيل](features/005-profile-design-polish.md).

## [0.2.0](releases/0.2.0.md)

- صورة دائرية في الشريط العلوي تفتح صفحة ملف المفتش والإعدادات.
- اختيار/إزالة صورة محلية، وتفضيلات لغة وحجم نص وتقليل حركة محفوظة محليًا.
- SliverAppBar قابل للانطواء وSliverList للصفحات المشتركة.
- توثيق إلزامي لكل ميزة وإصدار مع مخططات؛ لا توجد حزم Flutter جديدة.
- إصلاحات مراجعة Qodo: استعادة مؤكدة للإعدادات التالفة، فحص سياسة دون إعداد حزم،
  ومنع رسالة فشل اللغة أثناء التحميل أو الضغط المتكرر.

## [0.1.0](releases/0.1.0.md)

- الشاشات السبع، الزيارات والبحث والتصفية، المرفقات والمسودات والمحاضر.
- CI للتحليل والاختبارات وبناء Web وAndroid، وتسليم خاص تجريبي بالوسوم.
- معاينة Vercel تلقائية لفرع `preview` بعد نجاح CI لـ `main` المعتمد.
