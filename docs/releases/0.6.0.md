# 0.6.0 — التصفح واستكمال العمل المحلي

- [009: الزيارات والمحاضر والتنقل](../features/009-browse-and-navigation.md).
- [010: دليل الأنشطة وملف النشاط](../features/010-business-directory.md).
- [012: إصلاحات حالات البحث والتقويم والمسودات](../features/012-browse-review-fixes.md).
- بحث قابل للمسح، تصفية قابلة للتطبيق والإلغاء، وترتيب حسب الموعد أو الأولوية.
- حفظ البحث والتصفية والتمرير داخل الجلسة؛ رجوع التبويب إلى الرئيسية.
- البحث في المحاضر واستكمال المسودات دون إنشاء سجلات للزينة.
- لا حزم جديدة أو backend أو تغييرات في تخزين بيانات المستخدم الحالية.

```mermaid
flowchart LR
  Review[مراجعة قابلية الاستخدام] --> Browse[بحث وتصفية وحفظ سياق]
  Browse --> Directory[دليل من قوائم العينة]
  Directory --> Tests[اختبارات وتنقل وعربية وإنجليزية]
  Tests --> Visual[مراجعة المتصفح]
  Visual --> PR[فرع وPR ومعاينة دقيقة]
```

نجح 128 اختبارًا لـFlutter، منها 23 اختبارًا جديدًا، مع 3 فحوص سياسة SDK، فحص حدود
الملفات وتوثيق الحزم والمخططات، التنسيق والتحليل دون ملاحظات. نجح بناء Web
profile وrelease، وروجعت الواجهات في Chrome بالعربية والإنجليزية والخط الكبير.
اختبارات حواف التقويم وتسمية الرقم الضريبي وحجم نافذة التصفية أثبتت العيوب
قبل الإصلاح ثم نجحت بعده. لقطات المراجعة وروابط الميزات أعلاه.

CI وAndroid ومعاينة Vercel للـcommit النهائي تُوثق في PR. نشر المتجر والتشغيل
على جهاز حقيقي والمصادقة والإرسال الرسمي خارج هذه النسخة؛ التفاعل محلي تجريبي.
