# تفتيش — تطبيق المفتش الميداني

تطبيق Flutter عربي RTL مع تبديل للإنجليزية، مبني على الشاشات السبع المرفقة.
المستودع خاص. هذه نسخة تجريبية تفاعلية ببيانات نموذجية وليست خدمة ضريبية رسمية.

## الشاشات

1. الرئيسية: جدول اليوم، نسبة الإنجاز والزيارة القادمة.
2. زياراتي: البحث والتاريخ وتصفية المنطقة والأولوية والحالة.
3. تفاصيل الزيارة: بيانات النشاط، موقع توضيحي وفتح الاتجاهات وبدء الزيارة.
4. قائمة التحقق: بنود من قائمة منفصلة، ملاحظات ونتيجة المعاينة.
5. المرفقات: التقاط/اختيار صور وإرفاق PDF وإزالة المرفقات وملاحظاتها.
6. معاينة المحضر: ملخص، نوع الملاحظة، حفظ مسودة ورفع تجريبي محلي.
7. تفاصيل المحضر: QR حقيقي لمعرّف تجريبي، حالة ومرفقات وتفاصيل الزيارة.
8. الملف الشخصي: اضغط الصورة الدائرية في الأعلى لتغيير الصورة وضبط اللغة وحجم
   النص وتقليل الحركة. الرأس يستخدم SliverAppBar مثبتًا ينطوي عند التمرير.

في الإصدار 0.2.0 تُحفظ الصورة والتفضيلات محليًا بمعزل عن المسودات؛ يظهر رمز شخص
حتى اختيار صورتك من المعرض. لا توجد حزم جديدة أو حساب مصادقة فعلي.

الإصدار 0.3.0 يحسن صفحة الملف ببطاقة هوية، اختيارات منزلقة، معاينة قراءة وحركة
تحترم إعداد الجهاز والتفضيل المحلي. [توثيق التصميم](docs/features/005-profile-design-polish.md).

الإصدار 0.4.0 يضيف الترحيب والتعريف والدخول والتسجيل واستعادة كلمة المرور، مع
صورتين أصليتين مولدتين للتطبيق. النماذج **معاينة فقط**؛ لا تُنشأ حسابات أو تُرسل
رسائل، ولا تُحفظ كلمات مرور. يمكن فتح التجربة دون إدخال بيانات. يوجد مركز مساعدة
وخصوصية وإشعارات نموذجية قابلة للقراءة، وإنهاء مؤكد يبقي المسودات على الجهاز.
[الوصول](docs/features/006-access-experience.md) · [الأساسيات](docs/features/007-app-essentials.md).

يوجد أيضًا تبويب للمحاضر والمسودات، وحالات فارغة ورسائل أخطاء. تحفظ المسودات
محليًا عند الحفظ أو الرجوع، ويمنع فشل الحفظ مغادرة النموذج. اكتمال البيانات شرط
للرفع التجريبي. البيانات النموذجية في قوائم typed داخل `lib/data/sample_data.dart`.

## التشغيل — PowerShell

المطلوب: Flutter **3.35.4** / Dart **3.9.2**. خط Cairo مضمن ويعمل دون تنزيل وقت التشغيل.

```powershell
flutter pub get --enforce-lockfile
flutter run -d chrome
```

للتشغيل على Android: وصّل جهازًا وفعل USB debugging ثم `flutter run`.
ملفات Android وiOS وWeb مضمنة. بناء iOS يحتاج macOS/Xcode ولم يُختبر هنا.

أدوات shader في نسخة Flutter الحالية على Windows فشلت مع المسار العربي.
يوجد مسار بديل محلي يشير إلى المشروع نفسه؛ لا يحتوي نسخة مستقلة:

```powershell
Set-Location 'D:\Bussnis_projects\tax-flutter-build'
flutter build web --no-web-resources-cdn
```

عند استنساخ المشروع على جهاز آخر، اختر مسارًا بأحرف إنجليزية لتجنب المشكلة.

## الفحص

```powershell
dart tool/check_project.dart
dart tool/test_project_policy.dart
dart format --output=none --set-exit-if-changed lib test tool
flutter analyze --fatal-infos
flutter test --coverage --concurrency=1
flutter build web --no-web-resources-cdn
```

الفحص الآلي يفرض 300 سطر كحد أقصى لكل ملف مكتوب يدويًا وتوثيق الحزم المباشرة.
ملفات المنصات المولدة وملفات lock والأصول مستثناة. تفاصيل الأدلة الحالية في
[VERIFICATION.md](docs/VERIFICATION.md).

## قواعد التطوير

- SOLID، واجهات خدمات مستقلة، حقن اعتمادات وفصل العرض عن المنطق والتخزين.
- أسماء كود واضحة، مكونات صغيرة، ثيم مركزي، RTL ودعم تكبير الخط.
- كل مهمة جديدة في فرع مستقل وPull Request؛ لا تدفع مباشرة إلى `main`.
- اختبارات regression للسلوك الجديد وحالات الفشل.
- كل حزمة جديدة تُوثق في [PACKAGES.md](docs/PACKAGES.md).
- كل ميزة وإصدار له ملف Markdown ومخطط Mermaid داخل [docs](docs/README.md).
- أنماط الواجهة وSlivers والحركة في [UI_PATTERNS.md](docs/UI_PATTERNS.md).
- [AGENTS.md](AGENTS.md) هو مرجع القواعد للمساهمين والوكلاء.

CI يفحص القواعد والتنسيق والتحليل والاختبارات ويبني Web وAndroid debug APK.
CD مُعد لإصدارات خاصة تجريبية عند إنشاء وسم `demo-v*` بعد دمج PR معتمد.
أضيف إعداد معاينة Vercel تتحدث بعد الدمج في `main`، مع إلزام الوكيل بالتحقق من
commit المنشور وإرسال رابط المعاينة. مشروع Vercel مربوط بالمستودع، والفرع
`preview` يتحدث إلى آخر `main` بعد نجاح CI. رابط المعاينة:
[tax-flutter-mobile-preview.vercel.app](https://tax-flutter-mobile-preview.vercel.app).
تظل الميزات غير المدمجة في معاينات مستقلة. راجع [إعداد Vercel](docs/VERCEL_PREVIEW.md).
لا يوجد نشر متجر أو مفاتيح إنتاج. راجع [التطوير والتسليم](docs/DEVELOPMENT.md).

## حدود النسخة

- تاريخ جدول العينة ثابت: 11 نوفمبر 2026. وقت البدء والحفظ يسجل وقت الجهاز الفعلي.
- نسبة الإنجاز تبدأ عند 25% لأن القائمة تحتوي زيارة مكتملة واحدة من أربع.
- الخريطة رسم توضيحي؛ الاتجاهات تستخدم إحداثيات نموذجية وتفتح تطبيق الخرائط.
- لا توجد مصادقة أو API أو قياس GPS أو إرسال رسمي أو اعتماد حقيقي من مشرف.
- التخزين المحلي تفضيلات JSON للعرض التجريبي، غير مشفر وغير ملائم للبيانات الحساسة.
- أقصى حد 6 مرفقات للمحضر، 2 MB لكل ملف. PDF يُرفق؛ معاينته داخل التطبيق غير متاحة.
- إذن الكاميرا واختيار الملفات والعودة بعد إغلاق Android للنشاط تحتاج تحققًا فعليًا.
- لا تستخدم النموذج لحفظ بيانات ضريبية حقيقية.
